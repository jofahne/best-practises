
# My Coding Best Practises

## [Docker First](https://github.com/jofahne/best-practises/tree/main/docker_first)

Practical best practices for Docker-first local development: keep secrets and environment config outside the repository, load them through Docker Compose at runtime, and keep projects portable, reproducible, and safer for agent-assisted workflows. Clean repo, lower leak risk, simpler setup.

## [Jupyter Lab With Docker](https://github.com/jofahne/best-practises/tree/main/jupyter_lab_docker)

A polished ready to install JupyterLab workspace designed for reliable, professional notebook work. It shows a practical approach to reproducibility, smooth onboarding, and clean project organization, making experimentation easier to share, easier to revisit, and easier to trust over time.
